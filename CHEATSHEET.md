# 📋 Cheat sheet: messages to copy and paste to Claude

## Starting work
- `Do the next task in TASKS.md` (or just `Go`)
- `Do task T05` (use any task number)
- `Where are we? Explain like I'm 12.` Claude reads the roadmap and the latest notes, then tells you.
- `What's waiting for me?` Claude lists anything it needs from you.

## If a chat says 🔴 "another chat is working"
- Go back to that other chat. If you closed it or it's stuck, type: `Take over`
- To run a different task at the same time on purpose: `Do task T__ at the same time`

## While working
- `Explain that again, simpler.`
- `What does ___ mean? Add it to the glossary.`
- `Show me how to test this.`
- `I don't like ___. Change it to ___.`

## Finishing
- `Wrap up and save everything.` Claude writes the handoff note, updates the log and tasks, and merges its work.
- `Is it time for a fresh chat?`

## When something goes wrong
- `It's broken: ___` Describe what you see, or paste a screenshot.
- `Undo the last change.`
- `You seem confused. Wrap up so I can start a fresh chat.`

## Choosing the model
Look at the "Model size" column in `TASKS.md`. Not sure? Use **Sonnet**.

## Once a month (5 minutes)
- `Monthly check-in: summarize what we did this month, what's next, and anything that's out of date.`

## Every 3 months
- `Do the 3-month fact check: are any band or carrier facts out of date?`
