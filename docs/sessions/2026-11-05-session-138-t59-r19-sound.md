## In simple words (for the owner)
The app now has real sound effects instead of two computer beeps. They come from free sound libraries whose makers gave them away with no rights reserved ("CC0"), and they're credited anyway. Seven sounds: a tiny click when you pick a match tile or a chip, four notes going up for a right answer, two soft notes going down for "not quite" (never a buzzer), a rising chord when you finish a lesson, a bright run of notes when your streak grows, a smooth "whoop" up when a new lesson opens, and a deep radar ping when you start the daily review. In Settings there's a new **Volume** slider (60% to start), and "Play a sample" now plays four sounds in a row (pick, right, not quite, lesson done), with a blue ring for each.

**One honest thing:** I can't hear. I picked these by measuring them (their notes, length and loudness), not by listening. Please play a lesson with Sounds on and tell any chat if one sounds wrong. The pack has 100 sounds, so swapping one is easy.

## What was done
- **Where the sounds came from:** kenney.nl is still blocked from the cloud ("403"), but Kenney's "Interface Sounds" pack (CC0, 100 sounds) downloads fine from OpenGameArt. Six sounds come from it; the review ping comes from Robin Lamb's CC0 pack on OpenGameArt (made from the public-domain VCSL and VSCO 2 CE instrument libraries). Files used unchanged, renamed, in `app/src/sounds/`; credits with original names and links in `app/public/licenses/sounds-CC0.txt` (it ships inside the app, next to the fonts' licences).
- **How they were picked (by measurement):** every file's length, loudness (peak and RMS), brightness and the notes it plays, with ffmpeg and numpy. Chosen: right = `confirmation_001` (G-D-G-D going up, 0.29 s); not quite = `question_002` (G down to E, pure tones, 0.33 s; the "error" sounds were noisy buzzes); complete = `confirmation_004` (rising E major, 0.49 s); streak = `confirmation_002` (high bright run, 0.54 s); unlock = `maximize_006` (smooth rising sweep, 0.38 s); tap = `select_002` (0.04 s click); review = Lamb's `ding_deep` (a long ping, like sonar or radar). All under 34 KB.
- **The sound engine** (`app/src/sound.ts`): the files are baked into the app's code (`?inline`), because fetch can't read the app's own `file://` pages in Electron. Web Audio plays them, each with its own level so they sound about as loud as each other (about -16 dB before the volume; the tap about -25 dB). `play(name, at)` can schedule a sound for later and gives back a "never mind" for one that hasn't started (a screen that closes early). If a file can't be decoded, right and not quite fall back to the old tones. No sound before the first click or key: the sound system is set up when the app is idle after that first click (it takes about 55 ms, measured in R17, so never inside the click).
- **When each plays:**
  - pick a match tile or a chip: `tap` (`app/src/ui/AnswerTile.tsx`, `app/src/ui/Chip.tsx`); pick-one tiles are `quiet`, because their right / not-quite sound follows at once (`app/src/QuestionTypes.tsx`);
  - an answer: `right` / `notQuite` (unchanged place, `app/src/LessonPlayer.tsx`, on the next frame);
  - lesson complete: `complete`, 0.1 s in, with the burst's first ring (`COMPLETE.sound`, `app/src/LessonComplete.tsx`);
  - back on the path after a new lesson: `unlock` as the lock pops off (`ON_AIR.lockOff`, 0.85 s; `app/src/PathMap.tsx`); not after the last lesson;
  - streak grows: `streak` with the flame's flicker (1.65 s after a lesson's first finish; `app/src/ui/TopBar.tsx`);
  - start the daily review (Review tab or the path's card): `review` (`app/src/main.tsx`).
  - Reduce motion doesn't silence anything (sound isn't movement); the path's sound then plays at once.
- **Volume** (`app/src/ui/Slider.tsx`, a new building block, and the Sound card in `app/src/SettingsScreen.tsx`): 0 to 100% in steps of 10, 60% to start, shown in the code font beside the slider. Like the switch, a real see-through range input sits under our own track, fill and knob, so mouse, arrow keys and screen readers work; the focus ring goes on the knob (`app/src/theme/theme.css`). Letting go plays a right-answer sound at the new loudness (even with Sounds off: you asked). Saved in the save file (`volume`, checked in `app/electron/store.cjs`; an old save file gets 60). The slider is also on the hidden `#blocks` page.
- **Idea I55:** "Play a sample" plays tap, right, not quite, lesson done, 0.32 s apart, with one ring each (`SAMPLE.gap` in the speed file = `SAMPLE_GAP`); all done in 1.45 s.

## Notes for the next Claude
- `window.__sounds` (from `app/src/sound.ts`) records every sound started (`name`, `delay`, `gain`, `real`), how many files decoded (`ready`, `failed`) and each file's `seconds` and `peak`. The click tests read it instead of faking the sound card.
- Sounds set up for later are scheduled on the sound card's own clock (`AudioContext`); the effect cleanups call off ones that haven't started. A sound that already started plays to its end.
- Run click tests with `xvfb-run -a npx playwright test` in `app/` (no screen in the cloud otherwise).
- Kenney's full pack and Lamb's pack are easy to get again: `https://opengameart.org/sites/default/files/kenney_interfaceSounds.zip` and `.../ui_ogg.zip`. To swap a sound: replace the file in `app/src/sounds/`, update its `level` and `length` in `SOUNDS` and its row in the credits file.
