# 🖼️ Gallery: pictures of every screen

- `before/`: the app on 2026-11-04, before the redesign (taken in T58 at your window size, 620 × 960). Kept forever, to compare.
- `latest/`: made by every redesign session (from R01, with `npm run gallery` in `app/`) and replaced each time, so it always shows the newest look. Older versions are in the project's history. Each screen comes twice: at your window size (620 × 960) and wide (1280 × 800, the file names ending in `-wide`). The pictures use a made-up save file: 3 lessons done, a 4-day streak, some reviews due. From R03, `10-blocks` to `12-blocks-sheet` show every building block (button, pill, switch, answer tile, speech bubble, bottom sheet) from the app's hidden `#blocks` page.

The pictures are small WebP files. You can open them in the GitHub app on your phone.
