# 🖼️ Gallery: pictures of every screen

- `before/`: the app on 2026-11-04, before the redesign (taken in T58 at your window size, 620 × 960). Kept forever, to compare.
- `latest/`: made by every redesign session (from R01, with `npm run gallery` in `app/`) and replaced each time, so it always shows the newest look. Older versions are in the project's history. Each screen comes twice: at your window size (620 × 960) and wide (1280 × 800, the file names ending in `-wide`). The pictures use a made-up save file: 3 lessons done, a 4-day streak, some reviews due. From R03, `10-blocks` to `12-blocks-sheet` show every building block (button, pill, switch, answer tile, speech bubble, bottom sheet) from the app's hidden `#blocks` page. From R05, `01-path-map` opens scrolled to the current lesson (lesson 4 of unit 1), the way the app does.
- `latest/day/`: from R20, the same pictures in the **Day** look (light), with the same names (`npm run gallery -- --look day`, or `node tools/gallery.mjs --look day` after a build). `38-look-change` catches the look changing halfway (a cover in the old look's background fading away); in `latest/` it's Night turning into Day, in `latest/day/` Day turning into Night. The old `09-path-map-day` and `38-settings-day` are gone: the whole Day set replaces them.

- From R21: `40-start-screen` (the start screen, held up by a made-up slow start), `41-start-fade` (halfway through its fade, the path arriving under it), `42-welcome` and `43-welcome-goal` (the first-start welcome, with a brand-new save), `44-heatmap-empty` (the Heatmap before any lesson), `45-trouble-load` (the progress file couldn't be opened, "What happened" open) and `46-trouble-crash` (the app tripped over something). The error screens come from test doors in the app (`CELL_TEST_LOAD_FAIL`, `CELL_TEST_CRASH`); you'll only see them if something really goes wrong.
- From R22: `47-path-narrow`, `48-settings-narrow`, `49-match-narrow` and `50-lesson-complete-narrow` (a phone-narrow window, 360 × 640: the smallest the window goes is 360 × 560), `51-focus-ring` (the keyboard's ring on the current lesson, after Tab), `52-keys-sheet` (Settings, Keys, Show), `53-match-keys` (a match paired with the keys: 2, then B; 1 is picked, its number box filled in) and `54-tap-aim` (the keyboard's crosshair on a picture you tap).
- From idea I69: `55-savefail` ("Couldn't save your last change" on the path, after one Try again, so it says "Tried 2 times"). It comes from a test door (`CELL_TEST_SAVE_FAIL`); you'll only see it if saving really stops working.

The pictures are small WebP files. You can open them in the GitHub app on your phone.
